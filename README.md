# Character Manager — TP3 (Java Visual SIH-6406)

Proyek ini merupakan aplikasi manajemen karakter yang dibangun menggunakan bahasa pemrograman Java untuk memenuhi Tugas Praktikum 3 mata kuliah Java Visual (SIH-6406). Aplikasi ini memproses dan mengelola status karakter, termasuk melakukan verifikasi kondisi status hidup karakter melalui fungsi `isAlive()`. Selain itu, proyek ini dirancang dengan struktur pemrograman berorientasi objek yang rapi dan terorganisir.
